# Airflow 1.5

База проекта заменена на исходный код **Airflow 1.5** для CS:GO.

- Источник: [`cacamelio/airflow-sources-fixed`](https://github.com/cacamelio/airflow-sources-fixed)
- Каталог в источнике: `v1.5`
- Коммит источника: `120fd1f3a39cbd50fcb70572a1e9286eddefc57d`
- Решение: `opaihook.sln`
- Платформа: `Win32`
- Исходный toolset проекта: `v142`

Сторонние исходники и предсобранные библиотеки находятся в `Libs`. Отдельный vcpkg/bootstrap/online-setup шаг не используется.

## Текущий статус

Это первичный перенос исходного кода без изменений логики. Сборка и работа после инжекта ещё не проверялись.

В исходном проекте конфигурация `Debug` ссылается на `Libs/PolyHook/build32/Debug` и `Libs/PolyHook/build32/zydis/Debug`, но этих каталогов в источнике нет. Release-варианты PolyHook/Zydis присутствуют; конфигурации сборки будут приведены в рабочее состояние отдельно.
