## Сборка

Требуются Visual Studio 2022 с набором C++ (v143) и Windows SDK. FreeType и LuaJIT уже включены в репозиторий как готовые статические Win32-библиотеки в `dep`: ничего скачивать или устанавливать перед сборкой не нужно, vcpkg не требуется.

Откройте `millionware.sln`, выберите `beta release` и платформу `Win32`, затем выполните **Build → Build Solution**. Локальные пути к заголовкам и `.lib` настроены для всех Win32-конфигураций. Отдельная `lua51.dll` не требуется; JIT и FFI включены в `lua51.lib`.
